# Simulador QCL

Un simulador para el análisis de estructuras cuánticas
utilizando diferentes métodos numéricos.

## Autores

- Brenda Nayeli González Valenzuela
- Jaime Alejandro Moreno Franco
- Yadira Monserrat Beltrán Zepeda

## Métodos Numéricos Implementados

- Euler
- Runge–Kutta–Fehlberg (RKF)
- Leapfrog
- Numerov
